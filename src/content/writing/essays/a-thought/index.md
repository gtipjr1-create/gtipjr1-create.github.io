A framework. My standard. A philosophy of sorts.

Something I think about daily.

Thought should produce direction.

Direction should produce action.

Action should produce evidence.

Evidence should improve the next thought.

**Think → Plan → Execute → Observe → Adjust.**

Keep it simple.
